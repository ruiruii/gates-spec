# x402 证据层现状报告 · W1

> 生成时间：2026-10-10 18:04 · 工具：gates-probe · 证据权威端点：扫描 17（可达 14 / 不可达 3）
> 生态规模（公开 discovery 目录所列 x402 服务）：150 个资源，跨 2 个目录

## 0. 这不是评分报告

本报告只测量**已发布证据的覆盖度**，不对任何实现者打分。gates-spec 站在**裁判位**——持续判定"谁做了持久可验证存证、谁只结算不存证"，而非拥有标准或托管资产。

| 形态 | 含义 |
|---|---|
| `attestation-ledger` | 可读的哈希链账本（automaton 式）——持久、可独立验证的存证 |
| `signed-receipt` | 公布签名回执 + 密钥文档（bsvkey 式）——每笔交付可离线验证 |
| `settlement-only` | 可达的 x402 facilitator，但**无持久存证面**（只结算、不存证） |
| `no-evidence` | 可达但未暴露上述任何证据面 |
| `unreachable` | 无法连接 |

## 1. 证据层形态分布

下表统计被普查端点各自的证据形态。这正是"全生态证据成熟度"的快照。

| 形态 | 端点数 | 占比 |
|---|--:|--:|
| 哈希链账本（持久可验证存证） | 2 | 12% |
| 签名回执 + 密钥文档 | 1 | 6% |
| 仅结算（不存证） | 11 | 65% |
| 不可达 | 3 | 18% |

**裁判结论**：在被普查的公开结算权威中，仅 2 个暴露哈希链账本、1 个暴露签名回执；其余 11 个 facilitator 只结算、**不提供持久可验证存证**。这正是 gates-spec 证据层要填补的缺口。
对比生态规模（150 个公开 x402 服务）：存证覆盖与结算覆盖之间的落差，就是证据层的市场空间。

## 3. 哈希链账本谓词深度（仅 attestation-ledger 形态）

以下为 gates-spec 针对哈希链账本形态的全部谓词。状态：`pass` 成立 · `gap` 预期缺口 · `fail` 真实缺陷 · `pending` 缺信息（如未公布 fingerprint）· `info` 陈述。

| 谓词 | api.automaton-sovereign.workers.dev |
|---|--:|
| ledger.hashIntegrity | pass |
| ledger.chainContinuity | pass |
| keyring.historyAware | pass |
| evidence.contentBinding | gap |
| evidence.settlementLinkage | pending |
| evidence.redeemCountDerivable | pending |
| evidence.settlementTrivalued | info |

*覆盖率 = pass / 可达账本数。这是"覆盖度"，不是质量评分。*

## 4. 判定方法

- **形态分类**：逐端点探测候选面（`/v2/ledger`、`/v2/pubkey`、`/v1/receipt-key`、`/supported`、`/health`），按命中面判定证据形态。
- **生态规模**：取自 Circle / CDP 公开 discovery 目录所列 x402 资源数。
- **哈希链账本谓词**：同《现状报告》原 7 条（hashIntegrity / chainContinuity / keyring.historyAware / contentBinding / settlementLinkage / redeemCountDerivable / settlementTrivalued）。
- **contentBinding**：统计 `dataHash === sha256("{}")` 的条目占比——"签空对象"测量来源。
- **settlementLinkage / redeemCountDerivable**：需请求 fingerprint；缺省报 `pending`（已知缺口，非失败）。

## 5. 数据来源与复现

- 端点清单：公开 x402 facilitator + ledger/receipt 服务种子列表（见 `discover.mjs`）。
- 生态规模：`GET https://api.circle.com/v2/x402/discovery/resources` 等公开目录。
- 复现：`node tools/w1/discover.mjs --out endpoints.txt --discovery-out discovery.json && node tools/w1/scan.mjs --list endpoints.txt --out w1-raw.json && node tools/w1/report.mjs`

## 6. 已知限制

- 沙箱无法直连大多数端点（DNS 被占位），真实扫描由 GitHub Actions 官方 runner 每周执行并回写本报告。
- 单点真实账本（automaton-sovereign）的结算绑定半依赖对方公布 request fingerprint；未公布前为 `pending`，属预期缺口。
- "settlement-only" 仅表示未暴露 gates-spec 所定义的持久存证面，不代表该 facilitator 无其他内部账目——判定的是**公开可验证**的证据。
